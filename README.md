# 📱 Rick and Morty App - Android (Kotlin)

## 🚀 Descripción
Aplicación Android desarrollada en Kotlin que consume la API de Rick and Morty para mostrar una lista de personajes y su detalle.

## 🛠️ Tecnologías
- Kotlin
- Retrofit
- RecyclerView
- Coil
- Android SDK

## 📱 Funcionalidades
- Listado de personajes
- Visualización de detalle
- Consumo de API REST
- Manejo básico de errores
