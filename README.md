# Rick and Morty App - Android Kotlin

## Descripción
Esta aplicación muestra personajes de la **API de Rick and Morty**. Los usuarios pueden ver una lista de personajes y, al seleccionar uno, acceder a una pantalla con información detallada, incluyendo nombre, estado, especie, género, origen e imagen.  

La app está desarrollada en **Kotlin**, usando **Retrofit**, **Coil** para cargar imágenes y **RecyclerView** para el listado. El diseño incluye un fondo violeta, tarjetas redondeadas.

## Funcionalidades
- Consulta de datos desde la API de Rick and Morty.
- Lista de personajes con imagen y nombre.
- Pantalla de detalle con información ampliada de cada personaje.
- Manejo básico de errores ante fallos de red o de API.
- Interfaz intuitiva y agradable (tarjetas redondeadas, sombras, fondo violeta).
